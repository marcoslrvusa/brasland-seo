# Brasland · SEO Analytics

Painel de monitoramento de rankings orgânicos da Brasland (`brasland.com.br`).

- **URL:** https://marcoslrvusa.github.io/brasland-seo/
- **Fonte dos dados:** Data for SEO (projeto Brasland, Google.com.br, pt, desktop, leitura semanal).
- **Baseline:** 21/10/2026 — 40 keywords, 4 rankeando, SOV 0,51%, posição média 27,5.
- **Apresentação:** https://marcoslrvusa.github.io/brasland-seo/apresentacao/estrategia-pillar-clusters.html
- **Leitura ao vivo:** apenas no painel local (`python3 server.py` → `localhost:8787`); esta versão publicada é um retrato da última atualização.

Arquivo único, sem dependências de build: `index.html` (HTML + CSS + JS + logo embutidos).
